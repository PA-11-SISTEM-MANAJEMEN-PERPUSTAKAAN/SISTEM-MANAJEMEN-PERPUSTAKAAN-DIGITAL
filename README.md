# Panduan Penggunaan

## Login Menu
>Menu Pengguna Untuk Login dan Registrasi

Saat pertama kali membuka program, penggunakan akan diberikan opsi yang bisa dipilih di menu login

<img width="355" height="193" alt="Picture11" src="https://github.com/user-attachments/assets/a8f3d94d-0925-4167-97d4-a0f345eb9878" />


## Opsi Login

Jika pengguna memilih pilihan 1. Login maka  akan diminta memasukkan username dan password, program akan memverifikasi, jika sesuai maka akan lanjut ke menu user ataupun admin sesuai dengan role dari username/akun tersebut. Namun, jika username
dan password tidak sesuai maka program akan menyuruh untuk menginput Kembali, maksimal hingga 3, jika lebih dari itu maka otomatis keluar dari program.

<img width="467" height="127" alt="Picture12" src="https://github.com/user-attachments/assets/e2c4c9d1-3eec-4da9-ba04-7d75e71fce24" />


## Opsi Registrasi

Jika pengguna memilih pilihan 2. Registrasi maka akan diminta untuk membuat username dan password, dan system akan memeriksa apakah username tersedia. Jika tersedia (belum ada yang menggunakan) maka akan
otomatis berhasil menambahkan akun ke database

<img width="324" height="226" alt="Picture16" src="https://github.com/user-attachments/assets/7d10915d-ed51-4586-ac48-dc203150ee95" />

## Opsi Keluar

Jika pengguna memilih pilihan 3. Keluar, maka akan menyelesaikan program seketika.

<img width="359" height="132" alt="Picture14" src="https://github.com/user-attachments/assets/66a9edfe-d39f-4b2d-a2b9-3a776d19c4f1" />


## Akun Admin
Jika pengguna login menggunakan akun admin, maka akan masuk ke menu admin

## Menu Admin

Terdapat 7 opsi yang tersedia di menu admin, yaitu:
1. Tambah Buku
2. Hapus Buku
3. Edit Buku
4. Daftar Buku
5. Lihat Anggota Perpustakaan
6. Tambah Barang
7. Keluar

<img width="915" height="321" alt="Screenshot 2025-10-26 041933" src="https://github.com/user-attachments/assets/3f7d4922-43b8-4ac0-bc5d-33c46e15e756" />


## Opsi Tambah Buku

Jika memilih 1. Tambah, untuk menambahkan buku. Admin diminta memasukkan nama buku, genre, tahun terbit, dan jumlah, lalu program akan memverifikasi data yang di input. Jika sesuai maka buku akan di tambahkan ke
database json.

<img width="926" height="442" alt="Screenshot 2025-10-26 042114" src="https://github.com/user-attachments/assets/d8effe2c-6f84-4639-b781-5c0abd3274cc" />

## Opsi Hapus Buku

Jika memilih 2. Hapus, yaitu untuk menghapus buku dari database. Admin diminta untuk menginput buku mana yang ingin dihapus dan system otomatis akan menghapus seluruh data buku tersebut

<img width="557" height="317" alt="Screenshot 2025-10-26 042243" src="https://github.com/user-attachments/assets/a04aa597-71a4-418f-bd30-6faf75e770e6" />

>Pengguna bisa menghapus buku dengan menginout nomor urut buku

<img width="577" height="241" alt="Screenshot 2025-10-26 042319" src="https://github.com/user-attachments/assets/ff78f9ed-5003-481f-bf20-eedf450d3bcc" />

>Daftar buku setelah menghapus buku

## Opsi Edit Buku

Jika memilih 3. Edit, yaitu mengedit informasi dari buku yang dipilih, pertama admin diminta untuk memilih buku mana yang akan di edit, lalu akan masuk ke menu edit dan admin diberi pilihan lagi ingin mengedit
judul, genre, tahun terbit, jumlah buku, dan kembali ke menu edit awal yaitu di suruh memilih buku.

<img width="376" height="323" alt="Picture20" src="https://github.com/user-attachments/assets/00ba15ef-4f2a-468f-8765-e3ff0d11bd13" />


## Opsi Daftar Buku

Jika memilih 4. Daftar Buku, akan menampilkan daftar buku beserta infonya dari database json.

## Opsi Lihat Anggota Perpustakaan

Jika memilih 5. Lihat Anggota Perpustakaan maka akan menampilkan username dan role dari tiap pengguna yang telah login, info diambil dari database json.

<img width="335" height="225" alt="Picture22" src="https://github.com/user-attachments/assets/bf39a6aa-7bb6-4698-9b4b-27c2e5e8d5a0" />


## Opsi Tambah Barang

Jika memilih 6. Tambah barang, untuk menambahkan barang yang dapat ditukar user dengan poin, nantinya admin akan di minta untuk memasukkan nama barang, Jumlah, dan harga penukaran poin. System akan memverifikasi,
lalu barang di tambahkan ke dalam database.

## Opsi Keluar

Yang terakhir jika memilih 7. Keluar, maka akan log out dari akun admin dan kembali ke menu awal.

<img width="459" height="186" alt="Picture24" src="https://github.com/user-attachments/assets/ba773124-54b8-4162-ac14-eeb16681254d" />

## Akun User

Jika pengguna login menggunakan akun yang memiliki role user maka akan, masuk ke menu user yang dimana di menu ini terdapat beberapa fitur yaitu pinjam, kembalikan, daftar buku, top up, tukar poin, dan keluar.

## Menu User

Terdapat 6 opsi yang tersedia di menu user, yaitu:
1. Pinjam Buku
2. Kembalikan Buku
3. Daftar Buku
4. Top Up
5. Tukar Poin
6. Keluar

<img width="653" height="283" alt="Screenshot 2025-10-26 043032" src="https://github.com/user-attachments/assets/0d12d0d1-a7c9-4f3e-ac03-3bf0943a550e" />

## Opsi Pinjam Buku

Jika memilih 1. pinjam buku, maka akan menampilkan daftar buku dari database json dan pengguna diminta memilih buku, jika inputan valid maka stok buku yg di pijam akan berkurang 1 dari database dan pengguna akan
mendapatkan 10 poin

<img width="567" height="335" alt="Screenshot 2025-10-26 042800" src="https://github.com/user-attachments/assets/6dc6f160-4b14-44fd-8a4e-d6531b1131df" />

## Opsi Kembalikan Buku

Jika memilih 2. Kembalikan Buku, maka akan menampilkan daftar buku dar database json dan pengguna diminta memillih buku yang akan dikembalikan, jika inputan valid dan stok buku tidak lebih sama dengan jumlah
buku fix, maka stok buku akan ditambah 1 di database dan pengguna akan mendapatkan 10 poin

<img width="683" height="485" alt="Screenshot 2025-10-26 042905" src="https://github.com/user-attachments/assets/a7dd1f18-01b6-487e-a9b4-b387e0ce46bd" />

## Opsi Daftar Buku

Jika memilih 3. Daftar buku, maka akan menampilkan daftar buku dari database.

<img width="580" height="263" alt="Screenshot 2025-10-26 041725" src="https://github.com/user-attachments/assets/a096b46d-5d82-484a-a631-920adf31ed04" />

## Opsi Top Up

Jika memilih 4. Top up, maka user diminta memasukkan jumlah uang yang ingin dikonversi menjadi poin, jika input valid maka top up berhasil dan uang akan di bagi 1000 dan akan menjadi poin yang di simpan pada
database dan akan menampilkan bukti transaksi.

<img width="343" height="92" alt="Screenshot 2025-10-26 043325" src="https://github.com/user-attachments/assets/ffa8557d-40e1-459c-aef2-6b0d523285b1" />

>Struk invoice top up poin

## Opsi Tukar Poin

Jika memilih 5. Tukar poin, maka akan menampilkan daftar barang yang dapat ditukar serta harga poinnya, lalu user diminta menginput barang mana yang ingin titukar dengan poin, jika input valid maka stok barang akan dikurangi 1 dari database, dan poin user akan dikurangi juga pada database.

## Opsi Keluar

Dan yang terakhir jika memilih 6. Keluar, maka akan log out dari akun dan kembali ke menu login.
